# sqlx4k-postgres-pgmq

A small, focused Kotlin Multiplatform client around the PostgreSQL Message Queue ([PGMQ](https://github.com/pgmq/pgmq))
extension. Build reliable, asynchronous workers on top of PostgreSQL with first-class support for LISTEN/NOTIFY and a
simple consumer API.

```kotlin
implementation("io.github.smyrgeorge:sqlx4k-postgres-pgmq:1.17.0")
```

📖 See the [PGMQ documentation](https://smyrgeorge.github.io/sqlx4k/extensions/pgmq/) for the quick start, the consumer
API and topics.
