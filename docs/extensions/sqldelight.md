# SQLDelight

[SQLDelight](https://github.com/sqldelight/sqldelight) integration for type-safe SQL queries with sqlx4k: write your
queries in `.sq` files, and run the generated code on top of the sqlx4k drivers.

The integration lives in its own repository:
[smyrgeorge/sqlx4k-sqldelight](https://github.com/smyrgeorge/sqlx4k-sqldelight).
